# خطة حل مشكلة بناء ملف الـ APK ورفع الكود إلى GitHub

## 1. تشخيص سبب الفشل
- **عدم اكتمال رفع ملفات المشروع**: مستودع GitHub يحتوي حالياً على ملف الـ Workflow فقط بدون ملفات المشروع الأساسية (`package.json` ومجلد `android/` ومجلد `src/`).
- **فشل خطوة Node / Actions Setup**: استدعاء `npm install` يفشل على خادم GitHub لأنه لم يجد ملف `package.json`، بالإضافة إلى أن بعض إجراءات إعداد الأندرويد الخارجية قد تتعارض مع بيئة GitHub الافتراضية.

---

## 2. خطوات التنفيذ

### المرحلة الأولى: تحسين ملف GitHub Actions ليعمل بسلاسة 100%
- تحديث ملف الـ Workflow ليعتمد على بيئة الأندرويد المدمجة مسبقاً في GitHub Runners (`$ANDROID_HOME`) دون الحاجة لحزم طرف ثالث قد تسبب أخطاء.
- إضافة أمر قبول تراخيص Android SDK تلقائياً (`yes | sdkmanager --licenses`).
- ضبط إصدار Node.js و Java JDK 17 المتوافق مع Capacitor 6 / 7.
- التأكد من رفع الـ APK الناتج إلى GitHub Artifacts ليكون متاحاً للتحميل المباشر.

### المرحلة الثانية: إرشاد وربط رفع الكود إلى المستودع على GitHub
- تقديم خيارين لرفع الكود:
  1. **الرفع عبر سطر الأوامر (باستخدام GitHub Personal Access Token)**: توفير أمر مباشر وسريع لرفع كافة الملفات إلى المستودع بنقرة واحدة.
  2. **الرفع المباشر عبر واجهة Google AI Studio**: استخدام زر المزامنة المدمج في واجهة المنصة.

### المرحلة الثالثة: التحقق والتشغيل
- تشغيل الـ Workflow على GitHub والتأكد من إتمام البناء بنجاح.
- ظهور ملف `zatca-qr-reader-apk` في صفحة الـ Artifacts جاهزاً للتنزيل والتثبيت على أجهزة الأندرويد.
